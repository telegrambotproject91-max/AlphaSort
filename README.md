# Alphabet Sort Bot

A simple Telegram utility bot with two functions:

- A–Z sorting
- Z–A sorting

## Setup

1. Create a Telegram bot with BotFather.
2. Set the `BOT_TOKEN` environment variable to the bot token.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run:

```bash
python bot.py
```

The bot is designed as a direct utility destination: users interact with the sorting functions immediately after `/start` without redirects or unrelated services.
